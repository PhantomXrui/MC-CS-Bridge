记录日期：2026-11-04。这里记录可核对的操作和验证，不把旧聊天里的意图当成已实现结果，也不声称完整重现了所有历史开发步骤。

## 1. 整理独立公开副本

- 在 `exports/MC-CS-Bridge-open-source` 整理 Git 工作树，保留正在使用的原工程。
- 纳入 CS2 插件、relay、原生合成器、FX shader、MC Fabric 源码、地图工具和动作生成器。
- 保留上游 MIT 声明和署名，添加第三方说明、架构与构建文档。
- 发布实现代码和自写说明；游戏 VPK、Demo、提取资源、账号、存档、令牌、构建产物和私人日志不入库。
- 用 PhantomXrui 账号发布 `PhantomXrui/MC-CS-Bridge`，实际修改以 Git 提交历史为准。

## 2. 整理跨电脑配置接口

- 插件、relay、BridgeControl 读取绝对路径变量 `MCCS_ROOT`，缺失时明确报错。
- 插件构建提供 `CounterStrikeSharpApiDir`；原生构建提供 `ReShadeIncludeDir`。
- MC 互动配置与语音目录可通过工作区/系统属性指定。
- 地图渲染切割的默认路径和输出防护从工作区派生，修复新电脑仍要求旧 E 盘目录的问题。
- 通用物理提取采用 root 参数或 MCCS_ROOT。
- 没有声称所有历史工具都消除了硬编码；剩余路径与输入约定按工具写入文档。

## 3. 公开 F8 的实现及缺失依赖

- 启用实验宏才编译 F8，并检查 4 个必要的本地生成头文件。
- 不公开游戏原始 shader 和模型派生表；渲染文档列出生成工具输入及缺口，特别是武器生成器仍依赖已有基线。
